# 🤝 Contributing to TryHackMe Free Career Labs Roadmap

First off, thank you for considering contributing to this repository! 🎉

Our goal is to maintain the **most comprehensive, 100% FREE TryHackMe learning roadmap** across all major Cybersecurity Career Roles.

---

## 🛑 Strict Requirement: 100% Free Labs Only

> [!IMPORTANT]
> **NO PREMIUM OR VIP LABS ALLOWED.**
> Every room added or modified in this repository **MUST be completely free to access** on TryHackMe without requiring a paid subscription. If a room transitions to paid/VIP, please open an issue to request its removal or replacement.

---

## 🚀 How to Contribute

### 1. Suggesting New Free Labs
If you discover a great TryHackMe room that is 100% free and fits one of our career roles:
1. Check the existing roadmaps in [`roles/`](./roles/) to ensure it isn't already listed.
2. Open a new issue using the **Lab Suggestion Template**.
3. Provide:
   - Room Name & Direct Link
   - Applicable Career Role(s)
   - Difficulty Level (Info, Easy, Medium, Hard)
   - Key Tools & Concepts Taught

### 2. Reporting Broken or Paid Rooms
If a room link breaks or TryHackMe moves a free room behind a paywall:
1. Open an issue using the **Broken Link / VIP Status Report** template.
2. State the room name, role, and current status.

### 3. Adding Templates & Cheatsheets
We welcome improvements to:
- Writeup & Portfolio templates ([`templates/`](./templates/))
- Tool Cheat Sheets ([`resources/free-cyber-cheatsheets.md`](./resources/free-cyber-cheatsheets.md))
- Certification mappings ([`resources/certification-roadmap-mapping.md`](./resources/certification-roadmap-mapping.md))

---

## 📝 Pull Request Checklist

When submitting a Pull Request (PR):
- [ ] Verified that all suggested rooms are **100% FREE** on TryHackMe.
- [ ] Markdown tables and direct links (`https://tryhackme.com/room/<room-id>`) are formatted properly.
- [ ] Clear concise description of changes provided in the PR.
- [ ] No typos or broken links.
