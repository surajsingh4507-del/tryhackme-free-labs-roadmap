## 🌟 Why This Repository?

Transitioning into cybersecurity or mastering a specific career role can be overwhelming. While TryHackMe offers paid subscriptions, **there are hundreds of world-class labs available completely free**.

This repository organizes those free labs into **structured, role-based career roadmaps** for:
- 🛡️ **SOC Analysts / Security Analysts (L1/L2)**
- ⚔️ **Penetration Testers / Ethical Hackers**
- 🛠️ **Security Engineers & Defensive Architects**
- 🔍 **DFIR (Digital Forensics & Incident Response) Analysts**
- 🧠 **CTI (Cyber Threat Intelligence) & Threat Hunters**
- ☁️ **Cloud Security & DevSecOps Engineers**
- 🔴 **Red Teamers & Adversary Simulators**

## 📌 Snapshot of Top Free Labs by Role

### 1. 🛡️ SOC Security Analyst (L1/L2)
- 🔹 [OpenVPN Setup](https://tryhackme.com/room/openvpn) *(Info)* - Setting up attack box connectivity.
- 🔹 [Intro to SIEM](https://tryhackme.com/room/introtosiem) *(Easy)* - Concepts of SIEM, log collection, dashboards.
- 🔹 [Splunk Basics](https://tryhackme.com/room/splunk101) *(Easy)* - Searching logs, SPL queries, security dashboards.
- 🔹 [Wireshark Basics](https://tryhackme.com/room/wiresharkthebasics) *(Easy)* - Packet capture inspection & protocol filtering.
- 🔹 [Windows Event Logs](https://tryhackme.com/room/windowsevents) *(Easy)* - Investigating Event IDs 4624, 4625, 7045.
- 🔹 [Sysmon](https://tryhackme.com/room/sysmon) *(Medium)* - Telemetry analysis, process creation & network monitoring.
- 🔗 *View all 18+ free SOC labs in [`roles/01-soc-security-analyst.md`](./roles/01-soc-security-analyst.md)*

### 2. ⚔️ Penetration Tester & Ethical Hacker
- 🔹 [Nmap](https://tryhackme.com/room/nmap) *(Easy)* - Network scanning, port discovery, script engine.
- 🔹 [Burp Suite Basics](https://tryhackme.com/room/burpsuitebasics) *(Easy)* - Intercepting proxies & request modification.
- 🔹 [OWASP Top 10](https://tryhackme.com/room/owasptop10) *(Easy)* - Hands-on web application vulnerability exploitation.
- 🔹 [SQL Injection](https://tryhackme.com/room/sqlinjection) *(Easy)* - In-band, blind, and error-based SQLi.
- 🔹 [Linux PrivEsc](https://tryhackme.com/room/linprivesc) *(Medium)* - SUID, sudo rules, cron jobs privilege escalation.
- 🔹 [Pickle Rick](https://tryhackme.com/room/picklerick) *(Easy CTF)* - Hands-on CTF challenge room.
- 🔗 *View all 18+ free PenTest labs in [`roles/02-penetration-tester.md`](./roles/02-penetration-tester.md)*
