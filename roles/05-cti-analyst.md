# 🧠 Cyber Threat Intelligence (CTI) & Threat Hunting Roadmap (100% Free Labs)

> **Role Overview:** A CTI Analyst tracks threat actor groups (APTs), analyzes tactics, techniques, and procedures (TTPs), enriches Indicators of Compromise (IOCs), and provides actionable intelligence to defensive teams and executive leadership.

---

## 🎯 Key Competencies & Skill Matrix

```
       [ Frameworks ]          ──────────► ( MITRE ATT&CK, Cyber Kill Chain, Diamond Model )
                 │
       [ Threat Intel Platforms]───────► ( MISP, OpenCTI, AlienVault OTX )
                 │
       [ OSINT Reconnaissance ]──────────► ( Maltego, Shodan, Google Dorks, VirusTotal )
                 │
       [ Threat Hunting ]      ──────────► ( IOC Extraction, YARA, Threat Feeds )
```

---

## 🎓 Aligned Industry Certifications

- **Certified Threat Intelligence Analyst** (CTIA)

## 💻 Recommended Portfolio Projects for CTI Analysts
1. **APT Campaign Analysis Brief:** Select a known threat actor group (e.g. APT29 / Lazarus Group), map their TTPs across the MITRE ATT&CK Matrix, extract IOCs, and build an executive brief.
2. **MISP Incident Feed Integration:** Document how MISP feeds can be ingested into SIEM rules for automated IP/Domain blocking.
