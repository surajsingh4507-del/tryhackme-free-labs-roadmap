## 💼 Recommended Hands-on Portfolio Projects
1. **Threat Actor Profile & TTP Brief:** Select an active threat group (e.g., APT28, Lazarus, Volt Typhoon), map their known TTPs to the MITRE ATT&CK Navigator, and create an intelligence report.
2. **OpenCTI / MISP IOC Ingestion Guide:** Write a practical setup guide demonstrating how to ingest external threat feeds and automate indicator scoring for SIEM ingestion.
